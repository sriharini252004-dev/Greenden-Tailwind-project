# 🌿 Greenden – Plant Store Website

Greenden is a modern and responsive plant store website built using **HTML5** and **Tailwind CSS**. This project showcases a clean, attractive, and user-friendly interface for exploring indoor plants and gardening products. It demonstrates responsive web design and modern UI development using Tailwind CSS.

## ✨ Features

- 🌱 Responsive Landing Page
- 🛍️ Product Collection Page
- 📞 Contact Page
- 📱 Mobile-Friendly Navigation
- 🎨 Modern UI with Tailwind CSS
- 🌿 Hero Section with Call-to-Action
- 💚 About Section
- ⭐ Best Selling Plants Section
- 💬 Customer Reviews Section
- 📧 Newsletter Subscription
- 🦶 Responsive Footer

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Responsive Web Design

## 📸 Pages Included

**Home Page** – Features a hero section, about section, best-selling plants, customer reviews, and newsletter subscription.

**Products Page** – Displays a collection of plants in a clean and responsive layout.

**Contact Page** – Provides a simple and user-friendly contact interface.
